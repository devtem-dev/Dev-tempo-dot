# Challenge 008 – Import & Use FSCSS Library

**Level:** 5–6  
**Track:** 2  
**Deadline:** 62 hours

## Task
Import an existing FSCSS module library and build something with it.

### Allowed Libraries
- `st-core.fscss` (v2)
- `micros.fscss`
- `overlapui.fscss`
- Or any official FSCSS module

### Requirements
- Properly `@import` the library
- Use at least 2–3 features/components from the library
- Create a small meaningful UI (card, section, dashboard piece, etc.)
- Compile and show working result

## Submission
Folder with your GitHub handle + working files.
