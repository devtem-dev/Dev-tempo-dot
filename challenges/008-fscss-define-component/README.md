# Challenge 008 – FSCSS @define + Shorthands

**Level:** 5–6  
**Track:** 1  
**Deadline:** 62 hours

## Task
Create a simple reusable component using FSCSS.

### Requirements
- Use `@define` to create at least one reusable component (example: card, button, or badge)
- Use FSCSS shorthands (`bg`, `p`, `px`, `py`, `rounded`, `flex`, `center`, etc.)
- Apply the component to at least 2 elements
- Compile your `.fscss` file to CSS
- Show the final result in an HTML file

## Submission
Create a folder with your GitHub handle containing:
- `main.fscss`
- `style.css` (compiled)
- `index.html`
