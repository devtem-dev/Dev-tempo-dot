# Challenge 008 – Create Your Own FSCSS Module

**Level:** 6  
**Track:** 3  
**Deadline:** 62 hours

## Task
Create a simple but well-structured FSCSS module library.

### Requirements
- Follow FSCSS module standards
- Use `@define` for reusable parts
- Include clear tokens/variables
- Solve a real small problem (example: buttons system, cards, badges, alerts, etc.)
- Provide usage example
- Good structure and comments

## Submission
Your module folder + example usage.
